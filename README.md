# Manokriti — Landing Page

A clean, responsive static landing page using the Swiss International design direction.

## Easy updates

**Edit `content.js` to change most text, image URLs, and the contact link.** Keep the setting keys intact and replace only the values. Short copy is intentional so the site stays spacious and easy to scan.

Edit `styles.css` to change the visual system. Main tokens are at the top:
- `--background`
- `--foreground`
- `--muted`
- `--accent`
- `--border`

Edit `index.html` only when changing the page structure or adding/removing sections.

## Included

- HTML, CSS and vanilla JavaScript
- Mobile navigation
- Responsive single-page layout
- No login, payment, database, or backend
- No form collecting personal information

## Free hosting

Upload the contents of this folder to the root of a GitHub repository. Enable GitHub Pages in Settings → Pages and choose the branch/root folder. Static hosting is suitable for this site and can be free.

## Before publishing

- Replace `hello@example.com` in `content.js` with the email you want to use.
- Image URLs and the Inter font currently load from third-party services and require an internet connection. Consider using properly licensed, locally stored images if you want more control and reliability.
- Review the placeholder copy before launch.

## Security basics

This site does not process passwords, payments, or user submissions. Do not commit API keys, passwords, or private credentials. Keep your GitHub account secure and enable two-factor authentication.
